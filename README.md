# Sesgos y falacias

Guía interactiva de sesgos cognitivos y falacias lógicas con evidencia académica citada (DOI), detector de manipulación en 60 segundos y tres tests.

Sitio estático de una sola página. Sin build, sin dependencias: se sirve tal cual.

## Estructura

```
index.html          Página completa (HTML + JS embebido)
css/estilos.css     Estilos, tokens de marca y tipografías
assets/             Logo, favicon y fuentes autoalojadas (woff2)
```

## Desarrollo local

```bash
python -m http.server 8099
```

Abrir `http://127.0.0.1:8099/`.

## Contenido

19 sesgos cognitivos · 16 falacias lógicas · 10 conexiones sesgo-falacia · 12 preguntas de detección · 14 fuentes académicas · 3 tests.

Contenido educativo; no sustituye asesoramiento profesional.
